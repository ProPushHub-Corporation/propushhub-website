# PropushHub Website

Marketing site for PropushHub — website, CMS, mobile, desktop and ERP software development services.

## Run locally

Prerequisite: Node.js

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run lint     # type-check
npm run seed -- --dry-run   # validate the Firestore sample data (see DATA_TYPES.md)
```

See [CLAUDE.md](CLAUDE.md) for project structure and contribution workflow.
